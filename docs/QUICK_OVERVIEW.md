# AUBO S3 电池搬运项目 · 简洁讲解版

**公开仓库：** <https://github.com/CHANGJianshuo/meituan-aubo-s3-robotics>

**版本：** 2026-10-14 现场源码快照，含当天晚间完成的任务二 Web UI 实机版本。

## 一句话讲清楚

我们让 AUBO S3 机械臂用一件被动舌片工具搬运电池：先在仿真中验证动作，再平滑并保存轨迹，通过网页提交给实机执行，最后结合关节反馈和相机确认完成。

## 做了什么

| 任务 | 动作 | 实机结果 |
|---|---|---|
| 任务一 | 把红色电池搬到 T0，卸载后退出 | 一次启动完成 10 段；平滑版完整执行 90.439 秒 |
| 任务二 | 红 → 黄 → 蓝，依次放入 P1 → P2 → P3 | 最新一轮完成 30/30 段；网页记录约 214.5 秒 |
| 操作界面 | 在网页看相机、状态与进度，提交和停止任务 | 已接入真实执行链路及结果核验 |

任务二保留舌片参考朝向，绿块不搬运。每块电池复用同一套动作：**接近 → 插入 → 试提 → 抬升 → 搬运 → 预放置 → 接触 → 卸载 → 退出 → 撤离**。

## 用什么方案做

1. **复用任务一。** 保留 V1 工具、运动学模型、10 段搬运流程、轨迹导出和执行器，把任务二扩展成三个目标点的连续流程。
2. **核对场景并做仿真。** 结合 RGB-D、底图和控制柜关节状态建立现场场景；用 MoveIt 规划、Gazebo 接触仿真检查承托、放置、退出和固定朝向。
3. **平滑轨迹提速。** 通过五次样条及时间重分配限制速度、加速度和加加速度，同时保留停点；提速后再原样回放验证。
4. **保存轨迹驱动实机。** 浏览器连接本机 Web UI，经 SSH 把任务交给 NUC 上的 AUBO SDK 播放器；RPC 和 RTDE 记录执行反馈，结束后相机检查三块电池稳定落位。

```text
测量与场景 → 仿真验证 → 平滑轨迹 → 网页提交 → 实机执行 → 反馈与图像验收
```

## 结果应怎样理解

最新任务二有 30 次动作和 30 次阶段完成回执，播放器正常退出，没有自动重试。纯运动时间为 **114.009 秒**，网页全过程计时为 **214.525 秒**；后者包含检查和停稳等待，因此“四倍速”不是全过程耗时缩短四倍。

当前现场版本按操作者要求将关节跟踪误差改为只记录，仍保留起终点、停稳、状态等检查。它完成了**已测量固定场景中的轨迹执行**；更换摆位、工具或相机后需要重新核对。图像稳定和关节误差不能直接当作电池的绝对落位精度。
